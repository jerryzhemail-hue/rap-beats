# 论坛私信与用户功能测试用例

## 私信功能测试用例

| 用例编号 | 优先级 | 前置条件 | 操作 | 预期结果 |
|---------|--------|---------|------|---------|
| TC-MSG-001 | P0 | 已登录用户 | 获取会话列表 | 返回会话列表 |
| TC-MSG-002 | P0 | 已登录用户 | 发送私信给其他用户 | 创建会话并发送消息 |
| TC-MSG-003 | P0 | 已有会话 | 获取会话消息列表 | 返回消息列表 |
| TC-MSG-004 | P0 | 已有未读消息 | 标记会话已读 | 未读数清零 |
| TC-MSG-005 | P0 | 已登录用户 | 获取未读消息总数 | 返回未读数 |
| TC-MSG-006 | P1 | 已登录用户 | 给不存在的用户发私信 | 返回404错误 |
| TC-MSG-007 | P1 | 已登录用户 | 给自己发私信 | 返回400错误 |
| TC-MSG-008 | P2 | 未登录 | 访问私信接口 | 返回401未授权 |
| TC-MSG-009 | P1 | 已有会话 | 访问他人会话 | 返回404无权访问 |
| TC-MSG-010 | P1 | 高频发送 | 1分钟内发送超过30条 | 返回限流错误 |

## 用户资料功能测试用例

| 用例编号 | 优先级 | 前置条件 | 操作 | 预期结果 |
|---------|--------|---------|------|---------|
| TC-USER-001 | P0 | - | 获取用户资料 | 返回用户基本信息+论坛资料 |
| TC-USER-002 | P0 | 已登录用户 | 更新个人资料 | 资料更新成功 |
| TC-USER-003 | P1 | - | 获取不存在的用户资料 | 返回404 |
| TC-USER-004 | P1 | 已登录用户 | 更新资料简介超过500字 | 返回400错误 |
| TC-USER-005 | P0 | - | 获取用户发布的帖子列表 | 返回帖子分页列表 |
